# For My Khushi ♡ — Romantic Gift Website 💗

A romantic personal gift website created with love for Khushi, following the project roadmap defined in [`plan.md`](./plan.md).

---

## 🌸 Features

1. **Surprise Hero Landing**
   - Floating rose petals and soft glowing hearts background canvas.
   - Relationship milestone card with sweet live counters.
   - Ambient romantic music player (synthesizes gentle lofi chords with Web Audio API or lets you upload your favorite MP3).

2. **Cherished Moments (Polaroid Gallery)**
   - Real aesthetic memory polaroids with tape strips, gentle tilt, and subtle zoom.
   - Interactive Lightbox to view enlarged photos and captions.
   - Built-in photo uploader to easily replace with real photos of you & Khushi directly in the browser!

3. **A Letter for Khushi (Interactive 3D Envelope)**
   - 3D animated envelope with wax seal `K ♡`.
   - Tap the wax seal to crack open the envelope flap and unfold the handwritten love letter.
   - Editable directly in browser.

4. **Reasons Why I Love You**
   - 10 interactive romantic cards with progress bar and heart counter.
   - "Next Reason", "Previous", and "Shuffle" controls.
   - "View all reasons" modal.

5. **Forever Promise (Final Surprise)**
   - Pulsing heart animation with gentle glow rings.
   - Interactive Question: *"Will you promise to always stay by my side, Khushi?"*
   - Playful runaway "No" button (you can't say no!).
   - "Yes! Forever and Always 💖" button triggers celebratory confetti & fireworks celebration.

6. **Full Local Storage Persistence & Personalization**
   - Click "⚙️ Personalize" to change her name, your signature, or customize the letter.
   - Everything is saved directly in browser `localStorage`.

---

## 🚀 How to Run Locally

Since this is built with standard HTML5, CSS3, and Vanilla JavaScript, you don't need any complex build step:

1. Double click [`index.html`](./index.html) to open it directly in any web browser (Chrome, Edge, Safari, Firefox).
2. Alternatively, run a local live server:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.
